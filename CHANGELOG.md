# Changelog

## v0.1.0

- First release, for firmware 4.x.
- Adds Manage Mods to the More menu: turn installed mods on or off, with changes applied after a restart.
- Keeps a copy of each mod in `.adds/nickel-mod-manager/mods` so a mod that is off can be turned on again.
- Shows mods that failed to load separately, and asks before trying one again.
- Firmware 5.x and 6.x support is under development and not part of this release.
