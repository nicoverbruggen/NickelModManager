# Changelog

## v0.3

- Added firmware 6.0 support. Install `Kobo.tgz` on firmware 6.0; use `KoboRoot.tgz` on firmware 4.x.
- Added automatic restoration of enabled mods after supported full firmware updates on Qt6 firmware.
- Added support for Kobo 5.18 (superseded by 6.0 already) and Tolino 5.18 (some Tolino devices).
- Use Tolino's Bariol font for manager pages. Kobo keeps its Rakuten or legacy fonts.

## v0.2

- Fixed a display issue on Kobo Elipsa and Kobo Elipsa 2E devices.
- Fixed issues with fonts not displaying correctly on older devices.

## v0.1

- Initial release, for firmware 4.23 and newer.
